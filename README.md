# 🕷️ Web Scraping — IPL 2025 Statistics
### CodeAlpha Data Analytics Internship — Task 1

## 📌 Objective
Scrape IPL 2025 cricket statistics from Wikipedia 
using Python and save as structured CSV files.

## 🛠️ Tools & Libraries
| Tool | Purpose |
|---|---|
| Python | Programming language |
| requests | Send HTTP requests |
| BeautifulSoup | Parse HTML content |
| pandas | Save data to CSV |

## 📁 Files
- `Task1_webscraping_1.py` — Main scraper script
- `scraped_data/` — All scraped CSV files

## ▶️ How to Run
pip install requests beautifulsoup4 pandas
python Task1_webscraping_1.py

## 📊 Data Scraped
- IPL 2025 match statistics from Wikipedia
- League standings, most runs, most wickets
- End of season awards

## 💡 Key Concepts
- HTTP GET requests with headers
- HTML parsing with BeautifulSoup
- Multi-page scraping with polite delays
- Error handling for network failures

## 🔗 Data Source
Wikipedia — 2025 Indian Premier League
